# 課堂模板：每階段只做最小版本

依 [WORKFLOW](../02-WORKFLOW.md) 進行；不要先複製所有空表。`＜＞` 是替換處，教學提示不放進成品。固定路徑讓通用 skills 及下一個對話能找到成果。

| 模板 → 產出 | 必填最小內容 | 何時 |
|---|---|---|
| [01 Brief](01-brief.md) → `docs/01-brief.md` | 問題、目標、非目標 | D2 開場 |
| [02 PRD](02-prd.md) → `docs/02-prd.md` | 使用者、主流程、故事與 AC | D2 卡 B |
| [03 SRS](03-srs.md) → `docs/03-srs.md` | 驗證規則、錯誤、待決 | D2 卡 C |
| [04 SAD](04-sad.md) → `docs/04-sad.md` | 系統邊界與一張圖 | D2 卡 E |
| [05 SDS](05-sds.md) → `docs/05-sds.md` | 資料、API、畫面與模組 | D2 卡 E |
| [06 Test Plan](06-test-plan.md) → `docs/06-test-plan.md` | 6–12 個 TC、人工流程、追溯表 | D2 卡 F |

第一次課堂不要求填滿完整工程文件。先讓一條需求接到測試與操作結果；[IT 設備借用完整範例](../../02-補充/examples/it-asset/README.md)供課後看深度，其技術棧與規模不代表本課主線，不能直接複製。

[TRACEABILITY](07-TRACEABILITY.md)定義編號；[LESSONS](08-LESSONS.md)只記實際偏差與解法，沒有新發現時不湊紀錄。
[agent-rules](../../02-補充/templates/agent-rules/AGENTS.safe.md)是課後其他專案的參考，不覆蓋本 repo 的既有 `AGENTS.md`。本課只在下半段補小組決策。
[hooks](../../02-補充/templates/hooks/README.md)是選用示範，完成骨架後再考慮。
