# Grill With Docs

在已有規格、設計或決策紀錄的情況下，用文件作為訪談的共同背景。先找出已定事項，再問真正還需要使用者決定的問題。

1. 讀使用者指出的文件與專案中相關的規格、決策紀錄和現有成果。分清楚已定決策、可查事實、未決問題與彼此矛盾的說法；每個要問的問題都附上它依據的文件。
2. 沿用 `/grilling` 的訪談方式：按決策依賴分輪提問，每題給建議答案；能查到的事自行查，產品取捨由使用者定案。已定事項不重問，除非使用者明確要重開。
3. 共識形成後，按使用者的交付要求更新承載該決定的既有文件，沿用專案的名稱、編號和結構。新決定若影響其他文件，指出或修正相關引用；不另建一份會與原文件競爭的總帳。
4. 回報已定事項、仍待決的問題、文件改動與下一步。訪談本身不授權實作。
